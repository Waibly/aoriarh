# Scripts

- `audit/` : audits en lecture seule et fichiers de résultats associés.
- `maintenance/` : opérations ponctuelles de maintenance, de synchronisation ou d’administration.
- `bocc_poc/` : preuve de concept et sorties associées pour les bulletins officiels de conventions collectives.

Les scripts d’expérimentation liés au backend sont dans `backend/scripts/experiments/`.
