# Documentation

- `produit/` : positionnement et présentation du produit.
- `commercial/` : offres, acquisition, partenariats et emailing.
- `juridique/` : CGV et politique de confidentialité.
- `exploitation/` : déploiement, facturation et sécurité opérationnelle.
- `architecture/` : cahiers des charges et processus techniques.
- `recherche/` : travaux et rapports sur la recherche documentaire.
- `tests/` : plans et résultats de tests.
- `assets/` : logos et favicons utilisés pour les documents.

Les rapports datés décrivent un état de travail à leur date de production. Ils ne constituent pas automatiquement une documentation de référence actuelle.
